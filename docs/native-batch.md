# Native batch contract

Compiler 0.40.0-semantic.8 and contracts 0.40.0-semantic.74 accept the native
variants captured by NESQL++ 0.45.0-semantic.10. Source/Catalog revision stays 40.

The current extension adds typed Botania MiniFlower selection and named HeadRecipe
output/priority, Squeezer noContainerRule and gtFixed callbacks, and an incubator
zero-fluid presence rule. Default name comparisons bind the actual locale's native
Text observation instead of inventing an English or Chinese fallback. Trade
quantity references retain zero; cellFault explicitly preserves a native null
inventory viewer fault. These observations do not turn into consuming recipes,
empty storage cells, or claims that the underlying game callback succeeded.

New native fixtures replay through small integration targets batch_squeezer,
batch_botania and batch_references. They exercise the normal production library
without compiling the full historical unit-test body on a memory-limited host.

Firework recipeClass, flightPolicy and outputAmount form a closed tuple. Vanilla
uses RecipeFireworks / onlyWithChargeCell / 1. Et Futurum uses its exact
RecipeFixedFireworks class / alwaysWithPowder / 3. Only rockets use this output
amount; stars and fading still produce one item. The evaluator preserves the
fixed rule's absent empty Explosions list and verifies actual native examples.

The pinned EnderStorage overview admits exactly the registered global/personal
actions. Unsupported refresh actions are not inferred from a newer source tree.

Tool-material parts normally display the exact raw template NBT. A TGreg part
may explicitly carry displayBinding.kind=tgregInventory, the target version and
an observed material name. Its displayed item must retain registry/metadata and
all template NBT, adding only the previously absent material string. It cannot
replace an existing tag, substitute an arbitrary item, or alter consumption.
The original template remains a separate authoritative raw record. Absence of a
binding always requires exact template NBT; it is not an implicit fallback.

The current Java-owned specimens exercise these paths through the public Domain
validator. Cases with valid hashes but altered output amounts, invented actions,
missing bindings or changed material tags must fail. These are local specimens,
not a claim of live whole-pack or pixel acceptance.

Compiler 0.40.0-semantic.7 / contracts 0.40.0-semantic.73 add explicit raw
failure.inputs for firework probes and craftingListed/usageListedFor on crop
predictions. Raw malformed cells cannot overwrite occupied or out-of-range
cells, substitute another registry, or become unsafe display facts. Crop query
memberships must name distinct actual parents, and at least one native query
must list the row. The native coarse deduplication does not justify changing a
prediction's denominator or calculating unobserved combinations.

Binnie recipe domains are replay witnesses for that row, while the separate
Database is the complete catalogue. The existing domain validator still checks
every retained witness, chromosome binding and transformation; unreferenced
members are no longer duplicated into every recipe. Source/Catalog stay 40.
