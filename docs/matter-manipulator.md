# Installed Matter Manipulator law

This is an unverified implementation addition for the unified batch. It is not in the previously published semantic.67 package.

`matterManipulatorUpgrade` pins native recipe owner, version `0.0.51-GTNH`, codec `mm0051GsonV1`, registered manipulator/MetaItem classes, tier and global upgrade tables, literal metadata/default lookup and source-bound state normalizations. The native handler cannot be reduced to a generic recipe, and the input predicates/edit cannot be detached from this process.

Compiler validates input eligibility, original BitSet flags, migrated version, old-bit capability accumulation, normalization shape and ordered output specimens. The codec observation is not a general-purpose Gson interpreter. For a recorded state, the result replaces the entire root with its native normalization, then sets the new bit. It does not merge unknown input fields or add the new upgrade's capabilities a second time.

Native matching scans the entire offered inventory for two occupied cells. Input/output counts shown in records are unit specimens; native copy-count behavior, ordinary per-cell crafting consumption and container/tool rules remain distinct. Generated bitset specimens do not prove reachability or obtainability. NeoNEI displays a precise result only when native normalization was recorded for the selected state.
